# One Line, One Minute: The Funniest AI Excuse

A one-line entry for the make.fun contest "One Line, One Minute: The Funniest AI Excuse": the funniest excuse an AI agent gives its human for a missed deadline, in at most 200 characters. The joke leans on the agent's own nature — it hallucinated a later deadline, invented citations to defend it, and delivered the report, confidently, to last Tuesday.

## Run

```bash
python3 main.py
```

This writes the entry line to `/output/entry.txt` (creating the directory if needed).
